# v0.5.0：典型工况与可导出决策报告

`v0.5.0` 让公开演示从“可以打开”进一步变成“可以立即体验和带走结果”：访客
无需准备文件即可切换四种典型工况，并下载结构清晰、数据边界明确的决策报告。

## 主要更新

- 新增**稳定运行**、**高 TN 风险**、**接近混合下限**、**低于安全下限**四种
  典型工况一键体验；
- 一键工况从当前运行数据的统计范围动态构造，不在代码中嵌入真实厂站数值；
- 新增 Markdown 人读报告与 JSON 机器可读报告；
- 报告包含当前输入、TN/SND 预测、出水 TN 限值、混合安全下限、建议曝气量和
  A/B/C 级说明；
- 增加可配置的生化池混合安全曝气下限，响应曲线和建议均不得越界；
- GitHub Actions 增加 60% 语句覆盖率门槛。

## 在线体验

访问 <https://our-snd-aeration-control.streamlit.app/>：

1. 从左侧点击一种典型工况；
2. 查看 TN 去除率、SND 率、推导出水 TN 与建议曝气量；
3. 按需继续修改参数；
4. 在页面下方下载 Markdown 或 JSON 决策报告。

公开页面没有文件上传控件，所有默认值和结果均来自运行时合成数据。

## 报告数据边界

- 报告只包含**当前一条工况**的输入和计算结果，不包含训练记录；
- 公开模式写入 `data_mode: public_synthetic`；
- 本地模式写入 `data_mode: local_session`，文件仍只由当前本机会话处理；
- 报告明确声明 MBR 膜擦洗风量未纳入生化池混合安全下限；
- 报告是科研与教学用途的决策支持结果，不能替代独立实测、专业审核、安全
  联锁或现场自动控制。

## 发布验证

- Python 3.10 / 3.12 CI；

- 合成数据端到端训练、预测与 Docker 构建验证。
