# v0.4.0：公开演示与本地数据隔离

`v0.4.0` 完成了从可运行研究代码到公开作品集的交付闭环：任何人都可以直接
访问数据安全的在线演示，需要处理自有数据的用户则可通过一键脚本在本机导入。

## 主要更新

- 发布 [Streamlit 公开在线演示](https://our-snd-aeration-control.streamlit.app/)；
- 新增严格隔离的 `public` / `local` 双运行模式；
- 公开模式不渲染上传控件，只使用运行时生成的确定性合成数据；
- 增加 macOS/Linux 一键启动脚本与 Windows 双击入口；
- Docker Compose 仅绑定 `127.0.0.1:8501`，避免本地导入服务暴露到局域网；
- 增加 Streamlit 模式测试、公开/本地健康检查和 Docker 构建验证；
- README 增加在线演示截图、项目封面和可直接点击的演示入口。

## 数据安全边界

公开仓库和在线演示均不包含真实实验记录、训练模型或由私有数据计算的成绩。
本地导入需要 `SND_APP_MODE=local` 与 `SND_LOCAL_IMPORT=1` 两个开关同时存在，
CSV 只保存在当前 Streamlit 会话内存中。

## 使用方式

### 在线体验

访问 <https://our-snd-aeration-control.streamlit.app/>。无需安装，也不需要上传文件。

### 本地导入

macOS / Linux：

```bash
git clone https://github.com/xie176320/our-snd-aeration-control.git
cd our-snd-aeration-control
bash scripts/start_local.sh
```

Windows：克隆或下载源码后，双击 `scripts\\start_local.cmd`。

## 发布验证
