# 当日低/中/高三点校准模型

## 目的

同日重复实验往往共享未完全记录的批次基线。完全未见日期时，现有 OUR、
水质、温度和曝气特征可能不足以恢复这个隐含状态；仅更换模型不一定能够
解决批次偏移。

V4-C 因此把问题限定为：历史模型从旧日期学习总体关系，新日期先实测低、中、高三个曝气工况，用它们校正当天的预测偏移和局部斜率，再预测三个校准点之间的其他曝气工况。

## 无泄漏验证流程

1. 将一个日期的全部记录从基础模型训练中删除。
2. 只在该日期中选取最低、中间、最高三个不同曝气水平作为校准点。
3. 计算三个点的“实测值－基础预测”残差。
4. 用带岭正则的线性残差模型拟合当日截距和曝气斜率。
5. 只对该日期剩余、未参与校准的记录计算预测成绩。
6. 另做滚动时间验证：基础模型只允许使用目标日期之前的数据。
7. 对所有满足条件的日期汇总 R²、MAE、RMSE 和 90% 绝对误差分位。

该流程中，基础模型从未见过被验证日期；三个校准点有意作为部署时必须提供的当日信息，不计入盲测成绩。

## 评价输出

程序为每个目标输出基础模型与校准模型的 R²、MAE、RMSE、日期数、盲测记录数
和 90% 绝对误差分位，并分别执行整日留出与只用更早日期训练两种验证。

公开 CI 仅在确定性虚构数据上验证计算链路。真实记录数、日期范围和成绩不会
发布；授权用户应在本地运行并审查 `calibrated_evaluation.csv`。`--required-r2`
是发布闸门而不是预先承诺：任一验证方式未严格超过阈值，命令返回退出码 3。

## 现场使用条件

- 三个校准曝气水平必须高于污泥悬浮和混合安全下限。
- 建议覆盖当天计划搜索范围的低、中、高位置；每个工况稳定至少 1 个 HRT 后再取样。
- 三个点必须同步获得 TN 去除率和 SND 实测值，且记录最大/实时 OUR、温度、进水 TN/COD 和曝气量。
- 只允许预测三个校准曝气水平之间的插值；程序会拒绝范围外预测。
- 模型输出不能替代 DO、氨氮、TN、污泥沉积、回流稳定性及 MBR 膜通量/TMP 的现场安全判断。

## 不能这样解释

- 不能把同日校准成绩写成“新日期无需实测即可达到的跨日期 R²”。
- 不能使用随机拆分的同日重复记录成绩冒充未来日期性能。
- 不能把 TN 去除率推导的出水 TN 当作独立实测出水 TN。
- 不能为追求 R² 删除困难日期、把目标变量放入输入特征或在盲测记录上调参。
