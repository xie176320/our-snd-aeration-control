# SVR 集成模型说明

## 1. 模型定位

本项目当前使用的模型不是随机森林或 XGBoost，而是：

> **基于日期等权 SVR–PLS 集成与当日三点岭回归残差校准的自适应回归模型**

基础模型负责从历史 OUR、水质、温度和曝气数据中学习总体关系；当日校准层负责修正不同日期之间未被输入变量充分解释的批次偏差。

## 2. 支持向量回归原理

SVR（Support Vector Regression，支持向量回归）是支持向量机在连续变量预测中的应用。SVR 不要求每个样本都被完全拟合，而是在预测值周围设置一个宽度为 ε 的不敏感区间：

[
|y_i-hat y_i|leq arepsilon
]

误差位于该区间内时不计入惩罚；只有超出区间的部分才产生损失。其核心参数包括：

| 参数 | 含义 |
| --- | --- |
| C | 误差惩罚强度；过大可能导致过拟合 |
| ε | 不敏感误差范围；越大模型越平滑 |
| γ | RBF 核的作用范围；越大越强调局部样本 |
| kernel | 决定采用线性关系还是非线性核映射 |

SVR 通常适合特征数较多、样本量较小并含一定测量噪声的回归问题。

## 3. 线性 SVR 与 RBF-SVR

### 3.1 线性 SVR

线性 SVR 建立近似线性关系：

[
hat y=oldsymbol{w}^{T}oldsymbol{x}+b
]

它用于捕捉进水负荷、温度、OUR 与处理效果之间较稳定的总体趋势，优点是结构简单、跨日期波动较小；缺点是难以描述复杂的非线性响应。

### 3.2 RBF-SVR

RBF-SVR 使用高斯径向基核：

[

=
expleft(-gamma|oldsymbol{x}_i-oldsymbol{x}_j|^2

]

它能够描述曝气量、温度、进水负荷及菌群活性之间的非线性关系，但在小样本条件下对参数和异常批次更加敏感。

## 4. TN 去除率的双 SVR 集成

TN 去除率基础预测由 RBF-SVR 与线性 SVR 等权组合：

[
hat y_{mathrm{TN}}
=
0.5hat y_{mathrm{RBF-SVR}}
+
0.5hat y_{mathrm{Linear-SVR}}
]

当前参数为：

| 子模型 | 参数 | 主要作用 |
| --- | --- | --- |
| RBF-SVR | C=1.0，γ=0.01，ε=0.03 | 捕捉非线性及局部变化 |
| 线性 SVR | C=0.1，ε=0.03 | 保持总体趋势稳定 |

TN 模型训练前按日期取中位数，使不同日期具有近似相同的训练权重，避免记录数较多的日期主导模型。

## 5. 模型输入特征

当前精简特征包括：

- 温度；
- 曝气量；
- 进水 TN；
- 进水 COD；
- 异养菌实时 OUR；
- C/N；
- AOB 最大 OUR ÷ 异养菌最大 OUR；
- NOB 最大 OUR ÷ AOB 最大 OUR。

比值特征用于表达菌群活性结构，并减少异养菌、AOB、NOB 最大 OUR 之间的共线性。

所有特征在进入 SVR 前执行标准化：

[
z=rac{x-mu}{sigma}
]

这是因为 SVR 依赖样本间距离；如果不标准化，COD 等数值范围较大的变量可能掩盖 OUR、温度和曝气量的影响。

## 6. SND 率联合集成

SND 率由三个部分共同预测：

[
hat y_{mathrm{SND}}
=
0.40hat y_{mathrm{SND-SVR}}
+
0.35hat y_{mathrm{TN
ightarrow SND}}
+
0.25hat y_{mathrm{PLS}}
]

各部分含义如下：

- **SND RBF-SVR**：直接根据运行工况预测 SND 率；
- **TN→SND 岭回归**：先预测 TN 去除率，再利用 TN 去除率与 SND 率之间的相关性预测 SND；
- **PLS2 共享潜变量模型**：提取 TN 去除率和 SND 率的共同变化结构。

预测阶段不把真实 TN 去除率作为 SND 输入，以避免目标泄漏。

## 7. 集成模型的作用

线性 SVR 与 RBF-SVR 具有不同的误差特征：

- 线性 SVR 偏差可能较大，但通常更加稳定；
- RBF-SVR 拟合能力较强，但对局部数据分布更加敏感；
- 等权或固定权重集成可以降低单一模型预测过高或过低的风险。

一般形式为：

[
hat y_{mathrm{ensemble}}
=
sum_{m=1}^{M}w_mhat y_m,
qquad
sum_{m=1}^{M}w_m=1
]

固定权重可以减少在当前小样本上继续拟合元模型造成的过拟合风险。

## 8. 当日三点残差校准

完全未见日期时，历史输入变量不能充分解释不同日期的批次基线。因此，在 SVR–PLS 基础预测之后增加当日低、中、高三个曝气水平的残差校准：

[
hat y_{mathrm{cal}}
=
hat y_{mathrm{base}}+(a+bA)
]

其中：

- A 为曝气量；
- a 修正当天整体预测偏高或偏低；
- b 修正当天局部曝气响应斜率；
- a 和 b 由当天三个实测校准点通过带岭正则的残差回归确定。

基础模型负责学习历史总体规律，校准层负责适应当天的污泥状态、进水特性及其他未记录批次差异。

## 9. 验证输出与适用范围

程序在整日留出后使用当日低、中、高三个实测点校准，并只在剩余记录上
评分；同时执行只使用更早日期训练的滚动验证。公开仓库不发布私有数据成绩，
CI 中的合成指标仅证明实现可复现。任何本地 R² 只适用于：

1. 新日期已有低、中、高三个不同曝气水平的 TN 去除率和 SND 实测值；
2. 待预测曝气量位于三个校准点覆盖范围内；
3. 预测属于同日范围内插值，而不是完全未见日期的冷启动预测。

不能把通过门控的结果解释为“没有任何当日实测数据时的跨日期 R²”。也不能
使用随机记录拆分、把真实目标放入输入特征或删除困难日期来人为提高指标。

## 10. 主要优点与局限

优点：

- 适合日期组有限、同日存在重复记录的小样本结构；
- 能同时表达总体线性趋势和局部非线性关系；
- 按日期等权，减少同日重复记录引起的权重失衡；
- 校准层能够显著修正当日批次偏差；
- 模型发布设置 R² 门控，未达要求时不能标记为达标。

局限：

- 三点校准增加了当日检测工作；
- 只能在校准曝气范围内插值；
- 一次 R² 点估计通过门控不等于未来批次仍能保持；
- 仍需独立未来月份验证，并结合 DO、氨氮、TN、污泥悬浮和回流状态判断现场安全；
- 由 TN 去除率推导的出水 TN 不能替代独立实测出水 TN。
